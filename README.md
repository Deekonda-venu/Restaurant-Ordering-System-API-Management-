# Restaurant-Ordering-System-API-Management-
Developed a Spring Boot microservices-based Restaurant Ordering System using MySQL, OpenFeign, and Kafka. Built independent services for orders, menu, payment, kitchen, delivery, and notifications, with REST APIs, synchronous service communication, and event-driven asynchronous workflows.
